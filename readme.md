# 🎵 YouTube to MP3 Downloader (Stable Version)

เว็บแอปพลิเคชันสำหรับดาวน์โหลดวิดีโอจาก YouTube และแปลงเป็นไฟล์ MP3 คุณภาพสูงโดยอัตโนมัติ เวอร์ชันนี้เป็นเวอร์ชันหลัก (Stable) เน้นความรวดเร็ว เสถียร และใช้ทรัพยากรเครื่องน้อย

## 🌟 คุณสมบัติเด่น (Features)
*   **Best Quality Audio:** ดึงไฟล์เสียงคุณภาพสูงสุดจาก YouTube และแปลงเป็น MP3 (192kbps)
*   **Auto Thumbnail Embedding:** ดาวน์โหลดรูปปกคลิป (Thumbnail) แปลงเป็น `.jpg` และฝังลงในไฟล์ MP3 ให้อัตโนมัติ
*   **Maximum Compatibility:** ใช้มาตรฐานฝังข้อมูล `ID3v2.3` เพื่อให้รองรับการเปิดฟังบน Windows Media Player, เครื่องเสียงรถยนต์, และแอปเล่นเพลงบนมือถือทุกรุ่น
*   **Real-time Status:** มีหน้าต่าง Terminal บนเว็บ (Web UI) คอยรายงานสถานะการดาวน์โหลดแบบเรียลไทม์

## 🛠️ สิ่งที่ต้องเตรียม (Prerequisites)
1. ติดตั้ง Python 3.8 ขึ้นไป
2. ต้องมีไฟล์ `ffmpeg.exe`, `ffplay.exe`, และ `ffprobe.exe` วางอยู่ในโฟลเดอร์เดียวกับโปรเจกต์ (เพื่อใช้ในการแปลงไฟล์เสียงและฝังรูปภาพ)

## 🚀 วิธีติดตั้งและรันโปรแกรม

1. เปิด Terminal (หรือ PowerShell) แล้วติดตั้งไลบรารีที่จำเป็น:
   ```bash
   pip install -r requirements.txt

2. สั่งรันแอปพลิเคชัน: py app.py

3. เปิดเบราว์เซอร์แล้วเข้าไปที่: `http://127.0.0.1:5000`
